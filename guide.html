대상: 출원인·대리인·연구관리자 누구나기기: PC·태블릿·스마트폰필요한 것: 브라우저만 (설치 선택)

기능별 사용법 자주 쓰는 것부터

🔍전체 검색

헤더의 돋보기를 누르거나 Ctrl+K(Mac은 ⌘+K)로 문서 전체를 검색합니다.

  • 2글자부터 검색됩니다. 예: 신청료 보완요구 PPH 별지 제6호
  • 결과를 누르면 해당 화면으로 이동해 그 위치가 잠깐 노랗게 표시되고, 접혀 있던 예시·FAQ는 자동으로 펼쳐집니다.
  • 닫기는 Esc 또는 바깥 영역 클릭.

🎨테마 · 글자 크기 · 고대비

  • 테마 3종 — 헤더 태양 버튼을 누를 때마다 흰색 → 아이보리 → 검은색 순환. 서랍 메뉴에서도 직접 선택할 수 있습니다.
  • 글자 크기 — 서랍 메뉴의 작게/기본/크게.
  • 고대비 모드 — 서랍 메뉴에서 켜면 글자·테두리 대비를 강화합니다. OS에서 ‘고대비 선호’를 켜두면 자동으로 적용됩니다.
  • 선택은 기기에 저장되어 다음 방문에도 유지됩니다.

✅신청 전 체크리스트

보완 사례·체크리스트 화면의 21개 항목을 눌러 체크합니다.

  • 상단 진행 바에 완료 개수가 표시되고, 모두 체크하면 “제출 준비 완료!”가 나타납니다.
  • 체크 상태는 이 기기에 자동 저장됩니다. 앱을 껐다 켜도 유지됩니다.
  • 처음부터 다시 하려면 체크 초기화 버튼.

🗓️기한 계산기

절차·비용 화면 맨 아래 “기한 계산기”에서 심사 착수 기한을 자동 계산합니다.

  • ① 신청서 이송일(선택) — 있으면 우선심사 여부 결정 기한(이송일+7일)도 함께 계산
  • ② 결정서 발송일(필수) / ③ 유형 — 일반(2개월의 말일)·PPH(3개월의 말일)·초고속(1개월 이내)
  • 계산 예: 발송일 2026-11-10 + 일반 → 착수 기한 2027-01-31 (2개월이 되는 날 1/10이 속한 달의 말일)

🧬CPC 빠른 조회

CPC 조회 화면에서 첨단기술 공고 분야의 주분류(CPC)를 검색합니다.

  • 코드 검색: G06N → 인공지능·피지컬 AI 분야의 일치 코드만 강조
  • 분야명 검색: 로봇 바이오도 가능
  • 반도체·디스플레이·이차전지는 CPC 없이 ‘기술 직접 관련성’으로 판단한다는 안내가 별도 표시됩니다.

💬FAQ 91문항

FAQ 화면에서 질문을 눌러 답을 펼쳐 봅니다.

  • 상단 탭으로 8개 주제(일반, 실시, 인증기업, 연구개발, PPH, 기술분야, 초고속, 청년창업)별로 모아 보기
  • 검색창에 키워드를 입력하면 실시간 필터링(예: 만 39세 대비표)

🔗공유 · 인쇄

  • 이 앱 공유하기 — 서랍 메뉴의 버튼. 휴대폰에서는 공유 창이, PC에서는 주소가 복사됩니다.
  • 인쇄 / PDF로 저장 — 서랍 메뉴의 버튼. 메뉴·버튼은 빼고 전체 장이 이어서 출력되어 사내 배포 자료로 쓰기 좋습니다.

🔄버전 배지 · 갱신 알림

  • 헤더의 v2026.11.1 배지가 현재 반영 판본을 보여 줍니다.
  • 고시·공고가 바뀌어 새 판본이 배포되면 홈 화면 상단에 “새 버전 안내” 배너가 뜹니다. 확인을 누르면 다시 표시되지 않습니다.
저장되는 정보는? 테마·글자 크기·고대비·체크리스트·“확인한 버전”은 모두 내 브라우저(기기) 안에만 저장됩니다. 서버로 전송되거나 수집되는 정보는 없습니다. 브라우저 설정에서 사이트 데이터를 삭제하면 초기화됩니다.

앱 설치 · 오프라인 사용 한 번만 해두면 이득입니다

안드로이드 (크롬 등)

1) 헤더의 ⬇︎ 앱 설치 버튼 누르기 → 2) 확인 창에서 ‘설치’. 버튼이 보이지 않으면 브라우저 메뉴(⋮) → 앱 설치.

아이폰 (사파리)

1) 사파리에서 앱 열기 → 2) 하단 공유 버튼(⬆︎) → 3) 홈 화면에 추가 → 4) ‘추가’. 설치 버튼을 누르면 이 순서가 담긴 안내 창도 띄워 드립니다.

설치 후

  • 홈 화면 아이콘으로 실행하며 주소창 없는 앱 화면(스탠드얼론)으로 열립니다.
  • 오프라인 사용 — 첫 방문 때 필요한 파일을 자동으로 캐시합니다. 이후에는 지하철·비행기처럼 인터넷이 없어도 열람·검색·체크리스트까지 그대로 동작합니다. 다만 처음 한 번은 온라인에서 열어 주세요.
  • 새 판본 배포 시에는 다음 온라인 접속 시 갱신 내용을 받아옵니다(배너로 알림).
앱 설치는 선택 사항입니다. 설치하지 않아도 브라우저에서 모든 기능을 동일하게 쓸 수 있습니다.

문제 해결 이럴 땐 이렇게

‘앱 설치’ 버튼이 안 보여요
이미 설치되어 있거나, 브라우저가 설치 기능을 아직 인식하기 전일 수 있습니다. 페이지를 한 번 새로 고침해 보세요. 아이폰은 설치 버튼 대신 사파리의 ‘홈 화면에 추가’를 사용합니다. 주소가 HTTPS여야 하며, GitHub Pages 주소는 기본 HTTPS라 문제없습니다.
오프라인에서 열리지 않아요
오프라인 캐시는 첫 방문 때 만들어집니다. 온라인 상태에서 한 번 열어 둔 뒤 다시 시도하세요. 시크릿(사생활 보호) 모드에서는 캐시가 유지되지 않을 수 있습니다. 그래도 안 되면 앱을 지우고 다시 방문해 설치하세요.
갱신 배너가 계속 나타나요
배너의 ‘확인’을 누르면 해당 버전에 대해 다시 표시되지 않습니다. 계속 뜬다면 브라우저가 사이트 데이터를 저장하지 못하는(시크릿 모드, 저장 공간 부족, 데이터 자동 삭제 설정) 환경인지 확인해 주세요.
표가 화면에 다 안 들어와요
표가 넓은 경우 좌우로 밀어서 볼 수 있도록 설계되어 있습니다. 표 위에서 손가락(또는 트랙패드 두 손가락)을 좌우로 움직여 보세요.
체크리스트가 초기화되었어요
체크 상태는 기기·브라우저별로 따로 저장됩니다. 다른 기기에서는 각각 체크해야 하며, 브라우저의 사이트 데이터 삭제 기능을 사용하면 초기화됩니다.
검색했는데 결과가 없어요
2글자 이상으로 검색해 보세요. 접혀 있는 예시·FAQ 본문까지 검색되며, 결과를 누르면 자동으로 펼쳐집니다. 표 안의 일부 짧은 셀은 검색되지 않을 수 있습니다.

배포 · 관리 이 앱을 소유·운영하시는 분용

항목내용
배포GitHub 저장소에 파일 업로드 → Settings → Pages → Branch main / (root). index.html이 앱 본체, guide.html이 이 사용 안내서입니다.
사용 안내서 주소https://아이디.github.io/저장소명/guide.html — 앱 서랍 메뉴와 푸터에서도 연결되어 있습니다.
내용 수정index.html 안의 해당 장(Ⅰ~Ⅳ)을 편집하고 커밋하면 Pages가 자동 반영(1~2분).
판본 올리기고시·공고 변경을 반영했으면 version.json의 version 값을 올리세요(예: 2026.11.1 → 2027.1.1). 방문자에게 갱신 배너가 표시됩니다.
자동 변경 감지저장소의 .github/workflows/update-version.yml이 매주 월요일 지식재산처 고시공고 페이지를 확인해 변경 시 version.json을 갱신·커밋합니다. Settings → Actions → Workflow permissions에서 쓰기 허용 필요.
캐시 갱신 규칙서비스 워커 버전(sw.js의 CACHE 이름)을 바꾸면 방문자 캐시가 강제로 새로고침됩니다. 큰 내용 변경 시 함께 올리는 것이 안전합니다.
